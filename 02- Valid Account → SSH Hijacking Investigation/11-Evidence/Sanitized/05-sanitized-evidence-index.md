## Public GitHub Safety

The sanitized evidence is intended for portfolio publication.

The following must not be committed to the public repository:

* Passwords
* Private SSH keys
* Credential wordlists
* Authentication secrets
* API keys
* Tokens
* Unnecessary private configuration data
* Unredacted sensitive system information

## Evidence Separation

Project 02 maintains separate evidence categories:

### Attack Evidence

Documents the original controlled SSH activity.

### Telemetry Evidence

Documents Linux and Elastic observations generated by the activity.

### Detection Evidence

Documents the detection rule and separately validated alert.

### Investigation Evidence

Documents correlation and analysis of the observed events.

### Remediation Evidence

Documents containment, hardening, and final-state validation.

### Sanitized Evidence

Provides public-safe versions suitable for GitHub publication.

## Timeline Integrity

The original attack activity around **08:36 IST** remains separate from the later detection validation at **10:08:40.907 IST** and remediation validation activity.

This separation prevents validation and remediation events from being incorrectly represented as attacker activity.

## Evidence Integrity

All evidence in this directory must remain traceable to actual Project 02 telemetry, screenshots, queries, or validated remediation results.

No fabricated events, timestamps, alerts, or attack outcomes should be added.
