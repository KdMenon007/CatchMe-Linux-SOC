
# Attack Evidence

This folder contains screenshots related to the **Project 01 SSH Brute Force attack simulation**.

## Purpose

The screenshots document the attack activity performed from the Kali attacker machine against the Linux SOC endpoint.

## Attack Details

- **Attacker:** Kali — `192.168.1.10`
- **Target:** `soc-linux` — `192.168.1.16`
- **Service:** SSH — TCP/22
- **Target Account:** `socadmin`
- **Attack Tool:** Hydra
- **Attack Type:** SSH password guessing / brute force
- **Result:** Authentication failures
- **Successful Login:** Not observed

## Evidence

The screenshots support the following stages:

1. Attack execution from Kali
2. SSH authentication attempts
3. Detection validation
4. Attack completion

## Evidence Integrity

All screenshots represent activity performed in the controlled CatchMe Linux SOC lab.

No screenshot should be edited in a way that changes or misrepresents the original evidence.
