# Authentication Failure Hunt

## Project

**Project:** CatchMe Linux SOC — Project 01  
**Incident ID:** `CATCHME-LNX-001`  
**Scenario:** SSH Brute Force Detection  
**Target:** `soc-linux` (`192.168.1.16`)  
**Attacker:** Kali (`192.168.1.10`)  
**Target Account:** `socadmin`  
**Service:** SSH (`TCP/22`)

---

# 1. Query Objective

This document describes the primary KQL threat-hunting query used during Project 01 to identify repeated SSH authentication failures generated by the controlled password-guessing activity.

The query was used to identify relevant authentication events and establish the initial evidence required for further detection and investigation.

---

# 2. Threat Hunting Query

```kql
event.action : "authentication_failure" and source.ip : "192.168.1.10" and host.name : "soc-linux"
```
---

# 3. Query Breakdown

The query combines three conditions to narrow the Elastic SIEM results to the relevant Project 01 activity.

### Authentication Event

```kql
event.action : "authentication_failure"
```

Identifies authentication-failure events.

### Source Identification

```kql
source.ip : "192.168.1.10"
```

Restricts the results to the controlled Kali attacker system.

### Target Identification

```kql
host.name : "soc-linux"
```

Restricts the results to the Linux SOC endpoint.

---

# 5. Investigation Fields

The resulting events were reviewed using the following fields:

| Field          | Investigation Purpose            |
| -------------- | -------------------------------- |
| `@timestamp`   | Establish event timing           |
| `source.ip`    | Identify the event source        |
| `user.name`    | Identify the targeted account    |
| `event.action` | Identify authentication activity |
| `process.name` | Identify the associated process  |
| `host.name`    | Identify the affected endpoint   |

---

# 6. Observed Activity

The query identified authentication-failure events associated with:

```text
Source IP      : 192.168.1.10
Target Host    : soc-linux
Target IP      : 192.168.1.16
Target Account : socadmin
Process        : sshd
Event Action   : authentication_failure
```

The results provided the initial Elastic evidence for the SSH password-guessing activity.
