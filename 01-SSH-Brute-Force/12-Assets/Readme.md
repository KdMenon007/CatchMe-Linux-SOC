# Project Banner

## File

`assets/project-banner.png`

## Purpose

The project banner is the primary visual asset for **CatchMe Linux SOC — Project 01: SSH Brute Force → Compromise**.

It is used to visually identify the project across the GitHub repository and project documentation.

## Recommended Usage

Place the banner at the beginning of the main project `README.md`:

```markdown
![CatchMe Linux SOC - Project 01](assets/project-banner.png)
```

## Asset Requirements

* **Location:** `assets/project-banner.png`
* **Format:** PNG
* **Purpose:** Project branding / visual identification
* **Scope:** Project 01 only

## Content Recommendation

The banner should visually represent:

* CatchMe Linux SOC
* Project 01
* SSH Brute Force Detection
* Linux endpoint
* Elastic SIEM
* Attack → Detection → Investigation workflow

Avoid placing sensitive information, credentials, private IP details that should not be public, or fabricated alert/evidence information inside the banner.
