# Project Assets

This directory contains supporting project assets such as the project banner and other publication-safe graphics.

- Preserve existing assets and filenames.
- Add only assets actually used by Project 03 and suitable for publication.
- Do not store credentials, private keys, tokens, or raw sensitive telemetry here.
- If an asset is derived from evidence, document its source and any sanitization.

This documentation does not replace or rename any existing asset or README variant.
