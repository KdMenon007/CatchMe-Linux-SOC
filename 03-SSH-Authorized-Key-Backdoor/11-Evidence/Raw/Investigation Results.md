# Investigation Results — Evidence Capture Template

**Status:** Template only. No raw results are supplied by this file.

For each actual investigation run, record:
- Collection date/time and timezone
- Host and data source
- Tool or query and exact parameters
- Actual result count and relevant document/event identifiers
- Observed fields, including null or missing fields
- Screenshot/export filename and SHA-256 reference, if collected
- Analyst interpretation, clearly separated from direct observations
- Limitations and follow-up actions

Paste only genuine collected output into a clearly labeled evidence section. Do not infer or invent results to complete this template.
