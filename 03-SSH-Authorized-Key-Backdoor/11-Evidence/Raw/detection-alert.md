# Detection Alert — Evidence Capture Template

**Status:** Template only. This file does not assert that a detection alert fired.

For an actual alert, capture:
- Alert ID and rule name
- Rule status and execution time
- Alert timestamp and timezone
- Host, user, event identifiers, and populated fields
- Severity/risk score as shown by Kibana
- Related query and time range
- Screenshot/export reference and hash, if collected
- Disposition and analyst rationale

If no alert is found, document the exact search window, status filters, and query used. A no-result search is not proof of a detection-engine failure.
