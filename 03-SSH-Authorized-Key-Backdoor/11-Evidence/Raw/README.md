# Raw Evidence

This folder holds original evidence exports or notes retained for the CatchMe Linux SOC Project 03 investigation.

## Handling rules
- Add only evidence that was actually collected; do not fabricate or reconstruct missing raw events.
- Preserve source, collection time, timezone, query or command, and relevant host context when known.
- Keep secrets, credentials, private keys, and unnecessary personal data out of public releases.
- Do not edit an original to make it look sanitized. Create a separately labeled sanitized copy when public sharing is appropriate.

The existing files in this folder are left untouched by the additive documentation updater.
