# Linux SSH Journal — Evidence Capture Template

**Status:** Template only. This file contains no fabricated journal entries.

For a genuine collection, record:
- Endpoint hostname and timezone
- Journal unit or selector used
- Exact `journalctl` command and bounded time range
- Collection timestamp
- Actual output or a reference to the secured evidence file
- Relevant event timestamps and session/process identifiers where present
- SHA-256 hash and sanitization notes, if applicable

Keep raw output unchanged in the secured evidence location. Use a separate sanitized copy for public sharing.
