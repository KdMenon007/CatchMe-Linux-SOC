# Sanitized Evidence

This folder is intended for redacted copies approved for sharing or publication.

## Handling rules
- Add only real evidence derived from an identified source; do not invent or duplicate evidence merely to fill the folder.
- Preserve the material facts, timestamps, timezone, host context, and interpretation limits needed to understand the evidence.
- Document what was redacted and why, without exposing the sensitive value.
- Keep originals in an appropriately secured location; never overwrite original evidence with a sanitized copy.

An empty folder means no sanitized evidence has been added here yet. It does not mean evidence was missing from the investigation.
