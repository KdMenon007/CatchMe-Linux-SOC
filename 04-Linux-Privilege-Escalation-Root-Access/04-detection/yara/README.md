# YARA — Project 04

No YARA detection rule is claimed as validated for this project.

YARA is intended for matching patterns in files or memory. The current evidence primarily concerns Linux process execution, sudo authorization, cron behavior, and system configuration. No confirmed malicious file sample has been established as the basis for a project-specific YARA signature.

Add a `.yar` rule only when a representative sample or defensible pattern exists, and validate it against both positive and benign samples. Do not treat a generic privilege-escalation technique as a file signature.
