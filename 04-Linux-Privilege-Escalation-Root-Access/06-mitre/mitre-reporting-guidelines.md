# ATT&CK Reporting Guidelines — Project 04

## Required fields
- Technique ID and official technique name
- Observed behavior
- Host and timestamp window
- Evidence references
- Confidence and rationale
- Alternative benign explanation
- Limitations and follow-up validation

## Confidence guidance
- **High:** Direct, attributable artifacts corroborate the behavior.
- **Moderate:** Multiple reported evidence sources align, but original event documents or configuration artifacts have not yet been reviewed together.
- **Low:** Mapping is based on a hypothesis or partial telemetry only.

## Project-specific caution
The Task 8 activity was intentionally generated as a controlled lab test. Label it as such. Do not use ATT&CK mapping to imply that a real attacker compromised the host or that an Elastic alert fired.
